# EP.001｜美债回购为何引爆金价

> 状态：`published`（补录制作档案）

> 时长：39:52  
> 栏目：研究室

## 一句话摘要

从美国财政部债券回购、期限结构与现金管理出发，解释为何市场会把“长端供给压力被边际缓和”理解为对黄金和 Bitcoin 有利；同时说明这种机制不同于美联储量化宽松，也不足以单独证明资产上涨的因果关系。

## 核心问题

1. 财政部回购到底改变了什么：债务总量、市场流动性，还是久期供给？
2. 当财政部更多依赖短票、回购旧券并维持长券拍卖规模时，谁承担了期限和再融资风险？
3. 为什么同一组政策信号可能同时利好长债、黄金与 Bitcoin？三者分别在交易什么？
4. “金融压抑”在这里是事实、政策意图，还是市场对未来路径的定价？
