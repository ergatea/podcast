# 编辑规范

## 我们在做什么

Podcast 关注那些值得慢下来理解的问题。每一期都应该有一个清晰的问题意识、一组可核验的事实，以及对不确定性的诚实表达。

## 选题卡

一个好的选题 Issue 至少包含：

- 核心问题：这一期究竟要回答什么？
- 为什么现在值得做？
- 已知事实与待验证假设
- 可能的嘉宾、资料与反方观点
- 这一期完成后，希望听众带走什么

## 文稿审阅

- 事实、数字、引语要有来源。
- 把观点和事实分开写。
- 不用夸张标题替代论证。
- 对无法确认的内容明确标注不确定性。
- 录音前让至少一位非作者读者通读一次。

## 节目状态

`idea` → `researching` → `drafting` → `recording` → `review` → `published`
